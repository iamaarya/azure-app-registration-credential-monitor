# Review Notes

The repository intentionally has only three solution folders:

```text
01-Portal-Standard
02-Specific-App-Registration
03-Automated
```

The automated solution can optionally target a specific App Registration; therefore a fourth folder is unnecessary.

For a web application, the monitored identity is the Entra App Registration. Use its Application (client) ID, not the Azure App Service resource name.

No SendGrid is used.
